## About me

I'm the **Chief Technology Officer at [Tatweer](https://www.linkedin.com/company/tatweer-iq/)**. I lead the engineering behind digital-transformation platforms for government and enterprise in Iraq: architecture, delivery, security and the team that ships it.

Since April 2026 I've also owned **APKALLU Advanced Technologies**.

I've been writing code for **9+ years**. I started in 2017 with independent projects, research and reverse engineering, then went from full-stack developer to back-end team lead to CTO, and I still write code every day. I care about systems that are **fast, secure by design and built to run for years**.
